# `pages/collection.md`

The exhibit collection index page — uses `layout: collection` to render the full filterable item grid.

## Role

A minimal page file that activates the collection layout. Its body content is simply `{{site.description}}`, which is displayed above the item grid (depending on how `collection.html` renders `{{ content }}`). The actual grid is generated by `_itemlist.html` via the `collection` layout.

## Front Matter

```yaml
title: Our Collection
layout: collection
permalink: /collection
```

| Field | Value | Purpose |
|---|---|---|
| `title` | Our Collection | Displayed in the dark header band via `page.html` |
| `layout` | `collection` | Triggers `_layouts/collection.html` |
| `permalink` | `/collection` | Fixes the URL; must match the `url` in `_data/navigation.yml` for active nav state |

## Body Content

```liquid
{{site.description}}
```

Outputs the value of `site.description` from `_config.yml`. This is the only body content in the file. Note: the `collection.html` layout does not render `{{ content }}` before the item grid — the description may or may not appear depending on whether the layout includes a content slot above the include. See `_layouts/collection.html` for the exact render order.

## Variables Used

| Variable | Source | Purpose |
|---|---|---|
| `site.description` | `_config.yml` | Page body text |

## Layout Chain

`collection.html` → `page.html` → `default.html`

At the `collection` layout level, the URL (`/collection`) does not contain `"blog"`, so `_itemlist.html` is rendered (not `_postlist.html`).

## Used By

Nothing depends on this file directly. It is the entry point for the collection browsing experience.

## Customization Notes

- **Page title:** Change `title:` in front matter to rename the heading in the dark header band.
- **Description:** The page body (`{{site.description}}`) is a single line. Replace it with any Markdown content to display a custom introduction above the collection grid.
- **Permalink:** If you change `permalink`, update the matching `url` in `_data/navigation.yml` to keep the active nav indicator working.
- **To display posts instead:** Change `permalink` to include `"blog"` (e.g. `/blog`) — the `collection` layout switches to `_postlist.html` based on this URL substring check.
- **Subheadline:** Add `subheadline: "Your text here"` to front matter to display a subtitle above the main title in the header band (rendered by `page.html`).

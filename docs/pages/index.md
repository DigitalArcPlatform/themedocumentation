# The "Pages" Folder

```
├── pages/
    ├── index.md                  ← site root (layout: blank, fully custom HTML)
    ├── collection.md             ← collection index page (layout: collection)
```

This folder contains pages that are user-defined.

Add files here (for instance, an about.md with the url /about/) to add additional content that is not controlled by the programming that automatically generates an index of the files in _items .
